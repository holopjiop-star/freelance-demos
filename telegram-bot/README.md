# Telegram-бот для заявок

Демо-бот на чистом Python: принимает заявки, сохраняет их в SQLite и уведомляет администратора.

## Возможности

- команды `/start`, «Помощь», «Оставить заявку»;
- пошаговый диалог: имя → телефон → комментарий;
- сохранение заявок в `orders.db`;
- уведомление администратору о новой заявке;
- обработка обрыва сети без падения.

## Запуск без токена

```bash
python bot.py --selftest
```

Проверяет весь сценарий и наличие записи в базе. Токен и интернет не нужны.

## Диалог в консоли

```bash
python bot.py --demo
```

## Реальный запуск

1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env`.
3. Заполните `BOT_TOKEN` и `ADMIN_ID`.
4. Запустите:

```bash
python bot.py
```

## Структура

```
telegram-bot/
├── bot.py
├── .env.example
└── orders.db      # создаётся при запуске
```

## Что можно доработать под заказ

- кнопки с категориями услуг;
