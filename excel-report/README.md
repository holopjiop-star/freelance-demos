# Автоматизация Excel-отчёта

Демо на чистом Python: собирает CSV с продажами, считает показатели и делает Excel-отчёт с четырьмя листами.

## Возможности

- генерация демо-данных за 3 месяца;
- чтение нескольких CSV;
- агрегация: выручка, средний чек, категории, месяцы, топ-5 товаров;
- Excel с листами «Сводка», «По категориям», «По месяцам», «Топ товаров»;
- форматирование: заголовки, ширины колонок, числовой формат.

## Запуск

```bash
python report.py
```

Создаёт `data/sales_*.csv` (если их нет) и `report.xlsx`.

Пересоздать данные:

```bash
python report.py --reset
```

## Структура

```
excel-report/
├── report.py
├── data/
│   ├── sales_2026-01.csv
│   ├── sales_2026-02.csv
│   └── sales_2026-03.csv
└── report.xlsx
```

## Формат входных CSV

```
date;category;product;quantity;price
2026-01-15;Электроника;Наушники;2;4500
```
