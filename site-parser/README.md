# Парсер сайта → CSV и Excel

Демо-парсер на чистом Python: собирает данные с сайта, выгружает в CSV и XLSX.

## Возможности

- HTTP-запросы через стандартный `urllib`;
- разбор HTML через `html.parser`;
- пагинация (несколько страниц);
- выгрузка в CSV (разделитель `;`, UTF-8 BOM для Excel);
- выгрузка в XLSX без `openpyxl`.

## Запуск без интернета

```bash
python parser.py --demo
```

Использует встроенный HTML, результат появится в `output/`.

## Реальный запуск

```bash
python parser.py --pages 3
```

Собирает цитаты с `quotes.toscrape.com` — учебного сайта, созданного для парсинга.

## Результат

```
output/
├── quotes.csv
└── quotes.xlsx
```

## Как адаптировать под другой сайт

1. Откройте сайт в браузере и найдите CSS-классы карточек.
2. Замените условия в `QuotesHTMLParser.handle_starttag`.
3. Проверьте на одной странице, затем включите пагинацию.

## Ограничения

- Не обходит капчу и защиту от ботов.
- Не поддерживает JavaScript-рендеринг — только статический HTML.
- Для сложных сайтов нужен `playwright`/`selenium`.
